TURNERO DE CANCHAS DE PADEL

funciones!!

- Elegir un día y consultar los turnos disponibles.
- Ingresar el nombre del jugador.
- Reservar y cancelar turnos.
- Guardar las reservas en el navegador.




git hub pages (https://fcubilla.github.io/Mi-primer-Script-Interactivo/)

## Almacenamiento

Los turnos iniciales se cargan desde `db/data.json`. Las reservas se guardan en el `localStorage` del navegador: no se comparten entre usuarios, navegadores ni dispositivos.
